# dewquiz-data

VRChat の早押しクイズワールド **DewQuiz** が実行時に読み込む問題データです。
ワールドは `VRCStringDownloader` で、必要なファイルだけをここ(GitHub Pages)から読みます。

## 出典

- 問題文と答え: [Quiz Works](https://quiz-works.com/) に掲載のクイズ。
  Quiz Works の「[このサイトについて](https://quiz-works.com/about)」に
  「このサイトに掲載されるクイズはすべて自由に二次利用可能です」とあることに基づきます。
- 元にしたデータセット: [hpprc/quiz-works](https://huggingface.co/datasets/hpprc/quiz-works)(Hugging Face。2024年8月時点のクイズ)
- それより後に掲載されたクイズ: Quiz Works の各問題のページから取得(2026年10月)
- タグ・難易度: Quiz Works の各問題のページから取得(2026年10月)
- 入力用の読み: このワールドのために作成(漢字はひらがな、それ以外は元の表記)
- なぞなぞ(版4〜): [なぞなぞ＆クイズ nazo2.net(ナゾツーネット)](https://www.nazo2.net/) の
  子供向け・初級・中級・上級・大人向け/超難問 のなぞなぞと、その解説。**nazo2.net から使用の許可を得て掲載しています**(2026年10月)。
  ワールドでは、なぞなぞを出している間、モニターに出典(nazo2.net)を表示します。絵や図が要る問題・作家さんの問題は入れていません。
  通し番号 `meta.json` の `optInFrom` 以降がなぞなぞです

問題に問題がある場合は、Quiz Works の管理人ではなく、このリポジトリの持ち主にお知らせください。

## 中身

| ファイル | 内容 |
|---|---|
| `meta.json` | 版・問題数・1ファイルの問題数・タグ名の一覧・タグごとの問題数。版4〜 `optInFrom`(この通し番号から後ろは、ジャンルを選んだときだけ出す問題 = なぞなぞ)・`optInCredit`(その問題を出すときに表示する出典)・`optInTags`(ジャンルを選んだときだけ出すタグの番号。ワールドは一覧の最後に★を付けて並べる) |
| `q/000.json` … | 問題本体(100問ずつ)。1問 = `[id, 問題文, 表示用の答え, 入力用の読み, [タグ番号…], 難易度×100]`。なぞなぞは7つ目に解説(答え合わせで表示) |
| `tag/000.json` … | タグごとの `[通し番号, 難易度×100]` の一覧 |
| `diff/all.txt` | 全問の難易度を通し番号の順に1問1文字で。0.5刻みの境目に対する位置で、`A` = 1.00 ちょうど、`B` = 1.00〜1.50 のあいだ、`C` = 1.50 ちょうど … `Q` = 5.00 ちょうど |
| `filter/all.txt` | 絞り込み用の一覧(2026-10-06〜)。全問の難易度とタグを通し番号の順に。1問ごとに、難易度の1文字(`diff/all.txt` と同じ `A`〜`Q`)のあとにタグを1文字ずつ(タグ番号 + 0x100 の文字)続ける。区切りは無く、0x100 より小さい文字が来たら次の問題。新しい版のワールドはこれだけで絞り込む(`tag/` と `diff/` は前の版のワールドのために残す) |

- 通し番号は、問題の並びをシャッフルしてから振っています
- ファイル名と URL はワールドに焼き込まれているので、名前の付け方を変えないでください
