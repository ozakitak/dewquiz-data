# dewquiz-data

VRChat の早押しクイズワールド **DewQuiz** が実行時に読み込む問題データです。
ワールドは `VRCStringDownloader` で、必要なファイルだけをここ(GitHub Pages)から読みます。

## 出典

- 問題文と答え: [Quiz Works](https://quiz-works.com/) に掲載のクイズ。
  Quiz Works の「[このサイトについて](https://quiz-works.com/about)」に
  「このサイトに掲載されるクイズはすべて自由に二次利用可能です」とあることに基づきます。
- 元にしたデータセット: [hpprc/quiz-works](https://huggingface.co/datasets/hpprc/quiz-works)(Hugging Face。2024年8月時点のクイズ)
- タグ・難易度: Quiz Works の各問題のページから取得(2026年10月)
- 入力用の読み: このワールドのために作成(漢字はひらがな、それ以外は元の表記)

問題に問題がある場合は、Quiz Works の管理人ではなく、このリポジトリの持ち主にお知らせください。

## 中身

| ファイル | 内容 |
|---|---|
| `meta.json` | 版・問題数・1ファイルの問題数・タグ名の一覧・タグごとの問題数 |
| `q/000.json` … | 問題本体(100問ずつ)。1問 = `[id, 問題文, 表示用の答え, 入力用の読み, [タグ番号…], 難易度×100]` |
| `tag/000.json` … | タグごとの `[通し番号, 難易度×100]` の一覧 |
| `diff/easy.json` ほか | 難易度の帯ごと(簡単 1.00〜2.49 / ふつう 2.50〜3.49 / 難しい 3.50〜5.00)の通し番号の一覧 |

- 通し番号は、問題の並びをシャッフルしてから振っています
- ファイル名と URL はワールドに焼き込まれているので、名前の付け方を変えないでください
